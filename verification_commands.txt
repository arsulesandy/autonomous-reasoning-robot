FP.T01 (Reasoning predicates & assertions)
rosrun rosprolog rosprolog                                               # open Prolog shell
ensure_loaded('package://world_percept_assig4/prolog/fp_rules.pl').      # load predicates
observe_instance('Bottle','table',1.0).                                  # assert observation
observation_count('Bottle','table',C).                                   # expect C = 1
likelihood_of_surface('Bottle','table',P).                               # expect P ~ 0.67 with smoothing
preferred_surface('Bottle',S).                                           # expect S = table
search_target('Bottle',S,Conf).                                          # expect surface + confidence
needs_confirmation('Bottle').                                            # usually false with single dominant surface
decision_to_revisit('Bottle',S).                                         # suggests surface to revisit

Assert class/instance via ROS
rosservice call /assert_knowledge "object_name: 'CupRed'"                # expect confirmation: true, logs about new class/instance

Obstacle gating signals
rostopic echo -n 3 /learning/obstacle_distance                           # expect finite distances
